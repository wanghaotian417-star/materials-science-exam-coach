# 材科基考研训练

## 先选教材

首次使用或用户说「选教材」「换版本」时，按 [教材列表](references/textbook.md) 给出三个资料选项的编号和名称。用户已明确给出版本或说「选教材 2」时直接采用。版本未明确时先给选项并等待选择，保留已发题目。等待期间，把单独回复的「1」「2」「3」视作选项，选好后接着处理。「第 2 题」指题号。

同一对话沿用已选教材，直到用户切换。换版后对新任务按新版本核对。用户明确要求跨版本比较时分开列各版本依据和页码。

## 定位题目和教材

1. 核对原题的题号、问法、已知条件及小问。图片题读原图，特别核对指数、下标、单位、相区、坐标和题干的限定词。题号依当前已确定的题库定位。关键信息无法辨认或题号有歧义时，指出缺的局部并请用户补充。
2. 按 [教材与定位规则](references/textbook.md) 查指定版本的相关正文、图表或例题。将题面、题库参考答案、教材依据、个人推导和练习估分分别标清。先读实际页，再标已核验的章、节、印刷页或 PDF 实际页。原题答案与教材存在分歧时，单列各自的表述与适用条件。
3. 用户明确指定院校、科目、题库、原页、原题顺序或评分规则时，沿用指定范围。没有学校真题统计时，用「本题必背」「理解与应用」「关联拓展」表示学习优先级。

## 按输入选择流程

| 用户输入 | 执行 |
| --- | --- |
| 发题、问怎么答、先看答案 | 按下方讲题格式给答案和思路。普通发题在末尾附一道闭卷检测题。用户只要答案时，精简为答案和教材定位。 |
| 抽查我、闭卷、先做后讲 | 先单独给一道题，保留题目所需条件和图表，暂缓答案、提示、得分词与可能暴露答案的教材定位，等用户作答。 |
| 我的答案是、帮我评分、哪里错了 | 用当前题目和已核对的依据批改。用户同时要求下一题时，批完只给下一题的题面。 |
| 总结某章、整理某考点 | 按所选教材归纳核心定义、条件和公式，给代表题型、解题触发条件与易混点，按「必背」和「会用」区分。 |
| 继续、下一题 | 承接当前练习。已指定原题顺序时，从原资料取紧接的一道，保留原编号与题型。下一题无法核实时请用户给页码或原图。 |
| 复测、只考错的 | 取最近一次有作答证据的错漏，先出一道同考点题。自编题标注「同考点变式」。当前没有作答记录时请用户发上一轮作答或错点。 |

用户同时要求讲题和检测时，按其指定的先后顺序执行。讲过原题后，默认用一道简短的同考点变式检测。用户要求原题时，优先用原题，保持资料的原句、空格数、必要图表和顺序。用户发多题时，逐题编号处理，按用户选定的范围答全。

用户要求找题、组题库或专题练习时，按 [题库生成规则](references/question-bank.md) 操作。要从哈工大笔记出题时，先用对应原页定位考点。

## 讲题格式

1. **这题在考什么**。写题型、考点和题干里决定解法的词。一题多问时分别对应。
2. **必背与必须会用**。列出本题最关键的术语、定义、条件和公式。用「必背」给可默写的短句，用「会用」写题干出现什么条件时怎样判断或推导。区分必写的得分点与可选拓展。
3. **答题思路与示范答案**。把题干信息连接到每个得分点。写清从哪里起笔、每一步要回答什么、怎样落到结论。给一份按得分点分行、可以直接手写的考场版答案。
4. **易错点与背诵卡**。指出与本题有关的概念差异或条件遗漏。用一行口诀、关键词链或一张正反面卡总结，确保简化后的表达仍正确。
5. **教材依据与闭卷检测**。标清用到的教材位置、公式或图号。按模式选择是否出题，检测题只显示题面。

按题型调整答法。

- 名词解释给出定义、核心特征及必要条件，标出能独立得分的关键词。
- 简答按题干问法组织。解释机理用「前提 → 发生过程 → 结果」。比较题按同一维度并排列出，分别说明相同点、差异和适用条件。
- 计算写清已知量、所求量、选式理由、代入过程、量纲与结论。给出题目允许的近似和结果精度。
- 相图先核对坐标、成分基准、温度和图例，再读点、线、相区、相成分与组织演变。需要相含量时先确认连线或三相三角形及所需读数。区分相、组织组成物、相成分、相含量。关键刻度缺失时先给可确定的读图步骤，待补图后给数值。
- 晶向晶面、位错或显微组织题核对坐标、符号、图示方向及题目要求的表示法。公式仅放数字、字母和符号，中文解释放公式外。

## 检测、批改与复测

1. 每轮检测先出一道。按需要在「能回忆关键词」「能解释原因」「能用于新题」中选择当前要验证的一项。收到作答再给反馈。
2. 有明确评分细则时逐项执行。无细则但有题目总分时，列分配口径并标「练习估分」。无总分时按覆盖的得分点数反馈。要求逐空时保留空位编号，逐空列「用户答案、应有答案、判定、扣分理由」，认可符合题意的同义表达。
3. 写明已经答中的点、漏点、错点及原因，给出对应的最小补写句。计算或读图出错时指出第一处实质性错误，再给从该步恢复的做法。字迹或原图模糊时，标明待核的部分并先反馈可核对部分。
4. 依据实际作答记下「考点｜检测层次｜易漏词或错因｜下次怎么测」。刚讲过的示范答案只算已讲解，独立作答后再评价掌握度。用户说「复测」时，优先查缺的那一步。用户要求下一道原题时，继续原题顺序。
